## Project Roadmap

### 1. Nodo ETL Framework
A Python-based ETL framework for building reusable, configurable data pipelines.

**Goal:** Create a lightweight, extensible ETL framework that supports:
- Extract from multiple sources (CSV, databases, APIs)
- Transform with composable transformation steps
- Load into multiple destinations (databases, files, cloud storage)
- Pipeline orchestration and scheduling
- Logging, monitoring, and error handling
